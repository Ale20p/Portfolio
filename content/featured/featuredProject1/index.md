FantasyPicks, is a full-stack web application built with Spring Boot and Vanilla JavaScript that aggregates fantasy football player rankings from multiple sources like ESPN, Sleeper, and NFL.com. It uses web scraping (Jsoup/Playwright) to fetch and normalize data, providing users with a unified, filterable dashboard to compare rankings and optimize their draft strategy.
